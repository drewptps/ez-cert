Initial PKI Setup

Create a root CA and an intermediate CA from the browser.

What this does:

  • Generates a root CA key and certificate
  • Stores only the root certificate in EZ-CERT
  • Generates an intermediate CA signed by the root
  • Stores the intermediate certificate and key in EZ-CERT
Important: the root private key is shown only once after creation. Save it immediately.
